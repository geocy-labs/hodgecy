# Integral Lattice Engine

the exact integral-lattice layer introduces a geometry-neutral exact integer linear algebra layer.

## Matrix Convention

An integer matrix

```text
A in M_{n x m}(Z)
```

is interpreted as a homomorphism

```text
A : Z^m -> Z^n
```

acting on column vectors by `x -> A x`.

Thus:

```text
domain rank   = m
codomain rank = n
ker_Z(A)      subset Z^m
im_Z(A)       subset Z^n
coker_Z(A)    = Z^n / im_Z(A)
```

Every public the exact integral-lattice layer result uses this convention.

## Exactness

The engine accepts exact integer entries only, such as Python `int` and SymPy
`Integer`.  It rejects floats, nonintegral rationals, symbolic expressions, and
booleans.  There is no silent rounding.

## Rank

The rational rank is computed exactly over `QQ`.

```text
rank_Q(A) + dim_Q ker(A_Q) = m
```

the exact integral-lattice layer records this rank-nullity check.

For prime `p`, the modular rank is computed over `F_p`.  The modulus must be
prime.  Modular rank can drop at primes that see integral divisibility in the
matrix.  This is why source-level examples may agree over `QQ` but separate
modulo `2`.

## Smith Normal Form

The Smith normal form of `A` records invariant factors

```text
d_1 | d_2 | ... | d_r
```

with each `d_i > 0`.  SymPy provides the diagonal form and, in the current
environment, transformation matrices satisfying

```text
U A V = D
```

with `U` and `V` unimodular.  the exact integral-lattice layer verifies those identities when transforms
are returned.  If a backend does not expose transforms, invariant factors can
still be verified while transform data remain unsupported.

## Cokernel

From the Smith form,

```text
coker(A) ~= Z^(n-r) + Z/d_1Z + ... + Z/d_rZ
```

where factors `d_i = 1` contribute no torsion.

For example,

```text
A = diag(2,4)
```

has

```text
coker(A) ~= Z/2Z + Z/4Z
torsion order = 8
torsion primes = {2}
```

## Kernel

The integer kernel is returned as a matrix `K` whose columns are a `Z`-basis of
`ker_Z(A)` inside the domain `Z^m`.

```text
K in M_{m x k}(Z)
A K = 0
k = m - rank_Q(A)
```

The kernel of a homomorphism between free abelian groups is saturated.

## Image and Saturation

The image lattice is an embedded lattice

```text
im_Z(A) subset Z^n.
```

the exact integral-lattice layer records a column Hermite-normal-form basis when supported.

The saturation is

```text
Sat(im A) = (im A tensor Q) intersect Z^n.
```

For the example `diag(2,4)`, the image is generated by `(2,0)` and `(0,4)`,
while the saturation is all of `Z^2`.  The saturation index is

```text
[Sat(im A) : im A] = 8.
```

This agrees with the order of the torsion subgroup of the cokernel inside the
rational span.

## Lattice Comparison

the exact integral-lattice layer distinguishes:

- equality of raw matrix presentations,
- equality of embedded `Z`-lattices,
- equality of rational spans,
- abstract cokernel structure.

For example,

```text
L1 = span_Z{(1,0),(0,1)}
L2 = span_Z{(2,0),(0,1)}
```

have the same rational span but different integral lattices, and

```text
[L1 : L2] = 2
```

when read as `L2 subset L1`.

## Mathematical Firewall

An integer matrix has no inherent geometric meaning.  A source assembly matrix
is not a node-relation matrix.  Equal Smith normal forms do not prove geometric
complex isomorphism.  Equal rational rank does not imply equal integral
structure.  Equal modular rank profiles do not imply equal lattices.

the exact integral-lattice layer computes no source-to-node map, no vanishing-cycle relation, no
classical defect, and no Hodge atom.
